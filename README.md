## Executive Summary

**SkillVelocity AI** is an AI-powered personal learning intelligence platform designed for entry-level developers, coding bootcamp learners, and early-career data science practitioners. Rather than acting as a simple habit tracker, SkillVelocity AI applies end-to-end machine learning workflows—utilizing both **supervised classification** and **unsupervised clustering**—to transform study logs and coding sessions into predictive insights and scenario-based decision support.

---

## Core Product Experience

1. **My Dashboard**: Aggregates technical study logs, tracking active coding time, commit frequency, and core learning metrics.
2. **Pattern Intelligence**: Runs unsupervised **K-Means Clustering** on normalized technical activity features to discover behavioral learning profiles.
3. **Future Lab**: An interactive scenario-exploration simulator powered by a supervised **Logistic Regression Pipeline** that estimates milestone achievement probabilities.
